# Tagmar 0.16.8 — manutenção conservadora

- Base integral: 0.16.7, sem alterações em fichas, regras, magias ou compêndios.
- Comando de diagnóstico **somente leitura** para o Mestre no console F12: `game.tagmar1e.diagnosticarSistema()`.
- Relatório mostra versões, quantidade de atores, cenas, tokens Tagmar, tokens/protótipos ainda com barras e número de compêndios do sistema.
- Adicionada auditoria automatizada de regressão para os principais arquivos e pontos de integração.
- Atualizada mensagem antiga de versão no console.

## Limitações

A auditoria automatizada não substitui testes de interação no Foundry VTT 14. Nenhuma automação nova de combate ou magia foi adicionada nesta versão de manutenção.
