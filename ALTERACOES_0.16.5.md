# Tagmar 0.16.5 — tokens sem barras e ficha refinada

- As barras de Energia Física e Energia Heróica deixam de ser desenhadas sobre/ao redor dos tokens do Tagmar, inclusive os já existentes nas cenas.
- Os valores de EF/EH continuam intactos na ficha. Nenhuma configuração persistida de token é apagada.
- Melhoria visual da ficha: botões com áreas de clique maiores, abas adaptáveis, campos mais legíveis, foco de teclado, espaçamento e resumo numérico aprimorados.
- Preservadas as ações de configuração do token da 0.16.3 e as regras/compêndios.
- Observação: a ocultação é aplicada no cliente quando o sistema é carregado. Outros módulos que redesenhem barras após esse código podem interferir.
